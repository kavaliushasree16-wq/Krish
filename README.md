# Krish's Handicraft Store

A responsive e-commerce style website showcasing Rajasthani handicrafts.

## Features
- Product listing sections
- Order form and customer review area
- Mobile-first navigation
- Scroll animations using ScrollReveal.js

## Tech Stack
HTML5, CSS3, JavaScript, ScrollReveal.js

## Live Demo
[(https://kavaliushasree16-wq.github.io/Krish/)]

## Run Locally
```
git clone https://github.com/kavaliushasree16-wq/Krish.git
```
Open `index.html` in your browser.
